# SPEC2.3: リンク解析エンジン

[REQ2.1 — グラフ描画](../../要件定義/REQ2-リンクグラフ/REQ2.1-グラフ描画.md) の「マークダウンリンク」を解決するバックエンド実装。

## 設計

- 実装: `src/lib/links.ts`
- 入力: `FileRef[]`（全 Markdown ファイルの path と displayName）と readFile
- 出力: `{ nodes, edges }`。参照されなかったファイルは nodes から除外される

### リンク抽出

- **明示的マークダウンリンク**: `[label](url)` を正規表現 `/(^|[^!])\[([^\]]*)\]\(([^)]+)\)/g` で抽出（先頭の `!` を除外して画像記法は対象外）
- 本文中にファイル名（displayName）が現れるだけではエッジを張らない。エッジの元になるのは明示的なマークダウンリンクのみ

### 前処理

- フェンスコードブロック（\`\`\` / \~\~\~）とインラインコードは走査前にストリップし、コード例中のリンク記法をエッジにしない。フェンスの除去は `src/lib/markdown.ts` の `stripFencedCode()`（CommonMark 準拠の開閉判定）に委譲しており、\`\`\`\`markdown … \`\`\`\` のような入れ子ブロックの中身も丸ごと除去される

### resolveLink

- `#`・`?` 以降を除去
- `scheme:` 形式や `//` 始まりは外部リンクとして `null`
- 相対パスを `currentPath` のディレクトリ基準で解決し、`.` `..` を正規化
- 候補の順: 完全一致 → `+ "/README.md"` → `+ ".md"`
- いずれも `fileSet` に無ければ `null`

### キャッシュ

- `getCachedLinkGraph()` は `(path, mtime, displayName)` のタプル集合をシグネチャ化し、無変更ならメモリキャッシュを再利用
- 変更検知時のみ `buildLinkGraph()` を再実行
