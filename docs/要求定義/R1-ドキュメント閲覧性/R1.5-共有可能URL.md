# R1.5: 共有可能 URL

いま見ているドキュメントの URL を他の人に渡すだけで、同じドキュメントを開かせることができる。ファイル全体だけでなく、特定の見出し（セクション）を指した URL も共有できる。

## 要求

- 特定ファイルを開いた状態の URL を共有できる
- URL を受け取った人がそのリンクを踏むと、同じファイルが開いた状態でビューアが立ち上がる
- 戻る／進むなどのナビゲーション履歴を壊さずに URL が追従する
- ファイル内の特定の見出しを指した URL を共有できる
- そのリンクを受け取った人が踏むと、対象の見出しまでスクロールした状態でビューアが立ち上がる
